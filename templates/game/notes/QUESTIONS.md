# Câu hỏi phân tích game gốc

Mỗi câu: cần bằng chứng gì → trạng thái → kết luận (link ghi chú). Trạng thái: `mở` · `một phần` · `đã trả lời`.
Câu còn `mở` hoặc `một phần` phải ghi **ảnh hưởng nếu chưa rõ** (bản port sai ở đâu, chấp nhận được không). Từ P2, câu `mở` chặn cổng.
Xem skill re-notes; theo dõi bằng `npm run gk -- re`.

| --- | --- | --- | --- | --- | --- |
| Q1 | Ví dụ: tốc độ người chơi bao nhiêu, theo frame hay theo giây? | hằng số + hàm cập nhật vị trí | mở | | điều khiển nhanh/chậm hơn bản gốc |
